Flex

VTHacks III · 🏆 Winner: Microsoft - $100 Visa Gift Card

A budgeting app built at VT Hacks III. It maps your recent purchases so you can see where you spend the most, and uses natural language processing and data visualizations to sort spending into nine core categories, with location-based spending warnings. Team: Dag Yeshiwas, Jayanth Prathipati, John Purviance, Oliver Ebeling-Koning.

  • Python
  • Flask
  • JavaScript
  • Chart.js
  • Leaflet.js
  • OpenStreetMap
  • HTML5
  • CSS3

1ife

VTHacks Spring 2015 · 🏆 Winner: Bloomberg · 🏆 Winner: Capital One

1ife (“One Life”) gives budgeting advice based on income. It pulls profiles and annual income from the Capital One API and compares them with statistical data from the Bloomberg API. Team: Dag Yeshiwas, Denny Decastro, Steven Whitehead.

  • Python
  • JavaScript
  • D3.js
  • Capital One API
  • Bloomberg API

2023 – present · ★ 34 on GitHub

Sends a text alert when someone lists resale tickets for a sold-out Ticketmaster event. You run it with Node.js and pass a concert link; alerts go out through Twilio SMS.

  • JavaScript
  • Node.js
  • Twilio SMS

OneDuty

2019 – 2020 · ★ 7 on GitHub

A lightweight PagerDuty client that lives in the macOS menu bar. It shows who’s on call for your team, lets you look up any team’s schedule (including future dates) and pulls up the on-call contact details.

  • Swift
  • macOS
  • Xcode
  • PagerDuty API

DevFest Serverless Demo

2018

A serverless demo that sends subscribers a daily weather SMS. A CloudWatch rule triggers a Go Lambda, which gets the forecast from OpenWeatherMap and sends it through SNS. Dag later used Go Lambdas in production at Capital One.

  • Go
  • AWS Lambda
  • CloudWatch
  • SNS
  • OpenWeatherMap
